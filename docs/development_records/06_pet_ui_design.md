# 桌宠前端设计（Pet UI）

## 1. 需求

屏幕中央常驻云朵桌宠角色，点击桌宠即开始对话（语音输入），说话时头顶显示最新消息气泡，桌宠根据对话内容自动做出对应表情动作；右上角消息菜单可查看完整对话历史；支持联网获取最新热门桌宠内容。

## 2. 屏幕与软硬件事实（2026-08-11 确认）

- 面板：CO5300，390×450；固件 `CONFIG_LCD_LANDSCAPE=y`，逻辑分辨率待实机确认（预计 450×390）
- LVGL：9.1.0（`lv_image` 缩放/旋转、`lv_anim_timeline`、ARGB8888）
- 驱动：`LV_USE_NUTTX_LCD=y` + `lv_nuttx_init()` 可用（旧 demo `app/ai_agent` 已验证）
- 触控：`LV_USE_NUTTX_TOUCHSCREEN=y`（/dev/input0，FT6146）
- **`lv_nuttx_init()` 不启动渲染线程**，必须自建 pthread 循环调 `lv_timer_handler()`
- 原框架 `lvgl_ui_channel` 布局宏为 466×466 圆形屏（esp32s3-eye 遗留），需全部适配

## 3. 布局（450×390 横屏，以实机 fb 尺寸为准）

```
┌──────────────────────────────────────────┐
│                                ╭─╮        │
│                                │☰│ 消息菜单 │
│          ╭───────╮            ╰─╯        │
│          │ 气泡尾巴  │ 头顶气泡(仅最新1条)   │
│        ╭─╰───────╯─╮                     │
│        ╰──╮   ╭──╯                       │
│           │  ☁桌宠 │ 居中 ~300px           │
│           ╰───────╯ 点击=toggle 对话       │
└──────────────────────────────────────────┘
```

- 常态：桌宠居中 + 空闲浮动动画，无气泡
- 点击桌宠：弹跳动画 + 头顶气泡弹出（欢迎语）→ 自动开始录音
- 再点击桌宠：收起头顶气泡（toggle）
- 右上角消息按钮：全屏对话历史页（左蓝用户气泡/右白桌宠气泡，可滚动，顶部返回）

## 4. 交互流程（点击即说话，VAD 自动停止）

```
① 点击桌宠 → 弹跳 + 气泡弹出（"你好呀，我是小云 ☁️"）+ 自动开始录音
② 录音中：聆听动画 + 气泡"听你说…"；本地能量 VAD 静音 1.2s 自动停止
③ 思考动画（问号×3 依次浮现）→ ASR（火山引擎，联网后）
④ 用户文本 → 头顶气泡（左侧）→ LLM 回复 → 桌宠气泡（右侧）+ 说话动画 + TTS
⑤ 内容情绪判定 → 开心/疑惑/说话表情切换
⑥ 再点击桌宠 → 气泡收起；消息按钮 → 完整历史页
```

## 5. 情绪状态机与动画

```
空闲 ─点击→ 激活 ─录音→ 聆听 ─ASR→ 思考 ─回复→ 说话/开心/疑惑 ─→ 空闲
```

| 情绪 | 触发 | 动画 |
|---|---|---|
| 空闲 | 常态 | Y 浮动 ±6px 3s 循环 + 每 3s 眨眼（闭眼帧 100ms） |
| 激活 | 点击 | scale 1.0→1.15→1.0 弹跳 0.5s |
| 聆听 | 录音中 | rotate ±3° 摇摆 1s 循环 |
| 思考 | ASR/LLM 等待 | 问号×3 依次浮现（opacity+Y）+ 轻抖 |
| 说话 | TTS 播放 | 点头 Y±4px 0.5s 循环 + 腮红渐显 |
| 开心 | 回复含 哈哈/开心/❤/棒 | 上跳 + 闪光 ✦ 脉冲 + 腮红 |
| 疑惑 | 回复含 ？/不懂/是什么 | 歪头 rotate -12° + 问号常驻 |

表情层均为 LVGL 独立对象（label/arc），叠加在桌宠位图上，动画互不干扰。

## 6. 桌宠位图规格

- 源图：900×900 RGBA 白底云朵（contest 素材）
- 处理：抠近白背景 → alpha=0（保留云朵本体白）；边缘 1-2px 羽化防毛刺
- 缩放：220×220（显示 300px 由 lv_image scale 放大或直接生成 300×300）
- 格式：ARGB8888 C 数组，放 flash 引用（XIP，不占 SRAM）
- 帧：默认睁眼帧 + 闭眼帧（眼睛处横线遮罩，PIL 程序化生成）→ 眨眼

## 7. 模块划分

- `src/ui/pet_display.c/h`：桌宠位图 + 表情层 + 情绪状态机 + 动画（新增）
- `src/ui/chat_history_page.c/h`：全屏对话历史页（新增）
- `src/ui/assets/pet_cloud.c`：位图 C 数组（PIL 脚本生成）
- `lvgl_ui_channel.c`：改造——自包含 LVGL 引导（lv_init + lv_nuttx_init + 渲染线程）、新布局宏、头顶气泡、点击 toggle
- 录音：点击后 audio_capture + 本地 RMS 能量 VAD，静音 1.2s 自动停（阶段 B 音频驱动就绪后接入）

## 9. 风险与备选

| 风险 | 备选 |
|---|---|
| 横屏方向/分辨率与预期不符 | 阶段 A 先实机确认 fb 尺寸再定宏 |
| ARGB8888 渲染性能（120MHz MCU） | 转 RGB565 + 浅色 UI 主题 |
| 抠图边缘毛刺 | alpha 羽化 1-2px |
| VAD 误停/不停 | 能量阈值可调 + 最长录音超时（15s）兜底 |

## 10. 技术备忘

- 烧录：`sftool --connect-attempts 10`（stub 下载失败时重试）
- 板子恢复：RTS 复位（True 0.5~1s → False）
- 框架运行中 nsh 不可用；重启用框架 `restart` 或 RTS 复位
- 编译环境：PATH 含 prebuilts arm-none-eabi；ccache 转发脚本；pip pyelftools/cxxfilt
